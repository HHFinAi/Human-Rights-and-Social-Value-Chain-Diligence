# Operational economics and financial transmission

Read `../../AGENTS.md` and `../../prompts/stages/valuation.md` relative to this skill directory. Obtain the current stage packet using the repository CLI. Do not create or claim unavailable source access.

## Task
Quantify transparent wage-gap, disruption or remedial-cost scenarios with dates, populations and currency. Do not use the arithmetic to justify a rights violation or equate compensation with full remedy. Keep risk-to-people conclusions separate from investor economics.

## Deliverable
Return the fields in `../../schemas/artifact.schema.json`; use the current run ID and input digest. Required sections: wage_gap_scenario, supply_disruption, litigation_and_contracts, separate_people_risk. Include source IDs, scope, periods, methods and material gaps. Call only allowlisted calculations with explicit provenance; missing evidence means NEEDS_DATA, not invented values.

## Limit
Risks to people are not reduced to monetary loss or a supplier-spend score. Allegations, company responses and adjudicated findings remain distinct. No personal victim data should be published in public repositories.
