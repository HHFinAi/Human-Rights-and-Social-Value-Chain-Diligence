# People and value-chain mapping

Read `../../AGENTS.md` and `../../prompts/stages/stakeholders.md` relative to this skill directory. Obtain the current stage packet using the repository CLI. Do not create or claim unavailable source access.

## Task
Map workers, contractors, communities and users, including upstream/downstream tiers and vulnerable groups where evidenced. Protect personal identities; use aggregate or consented information. Do not infer abuse from nationality or geography alone.

## Deliverable
Return the fields in `../../schemas/artifact.schema.json`; use the current run ID and input digest. Required sections: affected_groups, tiers_and_business_relationships, worker_voice, data_protection. Include source IDs, scope, periods, methods and material gaps. Call only allowlisted calculations with explicit provenance; missing evidence means NEEDS_DATA, not invented values.

## Limit
Risks to people are not reduced to monetary loss or a supplier-spend score. Allegations, company responses and adjudicated findings remain distinct. No personal victim data should be published in public repositories.
