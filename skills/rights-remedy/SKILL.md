# Prevention, leverage and remedy

Read `../../AGENTS.md` and `../../prompts/stages/remedy.md` relative to this skill directory. Obtain the current stage packet using the repository CLI. Do not create or claim unavailable source access.

## Task
Evaluate grievance accessibility, non-retaliation, meaningful worker voice, remedy outcomes and independent verification. Policy adoption, audit completion or case closure alone is not remedy. Assess whether disengagement could worsen harm and identify escalation choices.

## Deliverable
Return the fields in `../../schemas/artifact.schema.json`; use the current run ID and input digest. Required sections: prevention_actions, access_to_remedy, verified_outcomes, disengagement_harm. Include source IDs, scope, periods, methods and material gaps. Call only allowlisted calculations with explicit provenance; missing evidence means NEEDS_DATA, not invented values.

## Limit
Risks to people are not reduced to monetary loss or a supplier-spend score. Allegations, company responses and adjudicated findings remain distinct. No personal victim data should be published in public repositories.
